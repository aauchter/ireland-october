# Ireland, early October

Shareable trip briefing for 30 Sep–12 Oct 2026. Draft plan, nothing booked except the flights.

**Live:** https://ireland-oct-briefing-2026.vercel.app

```bash
npm install
npm run dev
```

Dev server: http://127.0.0.1:4317

The map uses CARTO/OSM tiles with a trip route and labeled pins on top. Place and hotel photos are Wikimedia Commons images (copies also live in `public/photos`), credited under each picture. Hotel cards open official sites and Booking.com searchresults with the exact stay dates; no invented rates.
